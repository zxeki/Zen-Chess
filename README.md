# Zen Chess

Play chess in your browser: vs computer or 2 players, with timers and sounds.
Built with plain HTML, CSS, and JavaScript in a single file.

## Features
- Full chess rules (castling, en passant, promotion)
- Computer opponent with 3 levels
- Clocks, move list, and move review
- Drag and drop or click to move
